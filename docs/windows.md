# 使用说明

先安装 Microsoft Store / MSIX 版官方 Codex。下载 `CodexStartupWindows-Setup-1.0.0.exe`，双击即可安装到当前用户目录，并创建桌面、开始菜单快捷方式；不需要管理员权限或另装 Node。

首次使用先保存工作，在 Codex 菜单或托盘中彻底退出应用。关闭窗口可能仍有后台进程。安装器完成后点“启动并选择图片”，或打开桌面“Codex Startup Windows 设置”。

选择前半段头像和后半段背景，修改标题、小字、字幕与背景显现程度，点“保存并预览”。头像支持 PNG/JPEG/WebP；背景还支持 GIF 动图，单张不超过 30 MB。背景轮廓在本机自动生成；GIF 保存后继续循环播放，线稿取其中一帧。

以后使用“Codex Startup Windows”启动入口。动画在官方主窗口里播放约 12 秒，Esc 或点击跳过，结束后保留背景。`Ctrl+Alt+B` 随时打开设置。图片和文字保存在本机，不上传。

已有应用从本项目启动时，设置快捷方式可以复用本次会话。若已有官方应用是从普通入口打开，设置入口会提示彻底退出并重新打开，不会强制终止工作。普通启动入口在应用已运行时激活已有窗口。

“关闭美化，恢复 Codex 外观”移除本次注入。完全退出 Codex 再从官方图标打开，可恢复普通运行并关闭本次调试端口。已保存图片设置保留。

可在 Windows“设置 → 应用 → 已安装的应用”卸载 Codex Startup Windows。更新直接运行新版安装 EXE；更新、卸载不会清除保存在官方浏览器数据目录中的图片与文字。安装目录中的非本项目文件也会保留。

安装位置：`%LOCALAPPDATA%\CodexStartupWindows\app`。日志：`%LOCALAPPDATA%\CodexStartupWindows\launcher.log`。启动包使用随机 `127.0.0.1` 调试端口，校验官方路径、签名、用户、包身份和进程关系。端口随 Codex 进程保留，允许同机进程使用调试接口；没有常驻监控服务。

安装器目前未签名，Windows 可能显示未知发布者，请核对随发布提供的 SHA256。官方 Codex 不包含在安装器中。仅支持 Windows x64 的 MSIX 安装，其他渠道、ARM64 和后续版本未保证兼容。
