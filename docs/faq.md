# 常见问题

## 为什么关闭 Codex 窗口后，动画仍不能启动？

关闭窗口可能只把应用留在后台。先保存工作，通过 Codex 菜单或托盘彻底退出，再使用本项目的启动快捷方式。

## 必须每次打开设置吗？

不需要。第一次选好图片和文字后点“保存并预览”，以后从桌面的“Codex Startup Windows”启动即可。要修改时打开设置快捷方式或按 `Ctrl+Alt+B`。

## 动图为什么只有后半段支持？

前半段头像按静态头像显示；后半段背景支持 GIF，并保留原始动画。线稿来自其中一帧，随后会过渡到动态图。

## 为什么图片边缘被裁掉？

背景和线稿共用 3:2 的裁切平面，并根据窗口尺寸居中铺满。主体尽量放在图片中央；宽高比接近 3:2 时裁切较少。

## 怎么恢复普通 Codex？

在设置中点“关闭美化，恢复 Codex 外观”，或彻底退出后从官方图标启动。卸载可在 Windows“已安装的应用”中进行。

## 能用原来的 Codex 图标启动吗？

本项目创建独立的启动快捷方式。要播放动画，请使用“Codex Startup Windows”；官方入口仍按官方方式启动。

## 提示未知发布者怎么办？

当前安装器未签名。确认文件来源并核对同批发布的 `SHA256SUMS.txt`；不要使用来源不明或校验不一致的安装包。

## 报错信息在哪里？

查看 `%LOCALAPPDATA%\CodexStartupWindows\launcher.log`。反馈时附 Windows 版本、Codex 安装渠道和版本及报错文字；不要发送账户资料或完整浏览器数据目录。
