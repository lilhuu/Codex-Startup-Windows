# Windows 一键安装项目设计

用户确认交付为单个安装 EXE。项目名 Codex Startup Windows，独立整理自 M1ddle0/codex-startup-animation 及本地 Windows 移植。个人版启动器、亚丝娜素材和桌面入口保留原样。

安装器把内嵌 ZIP 安装到当前用户的 LocalAppData/CodexStartupWindows，不要求管理员或第三方运行时。创建桌面、开始菜单启动与设置入口，并提供当前用户卸载入口。更新保留图片和文字；安装失败回滚文件，不碰官方 Codex 安装目录。

用户打开启动入口后，使用官方 MSIX 激活接口，校验 OpenAI 进程、用户、包身份及回环调试端口，再注入原项目的 12 秒动画。设置入口在新启动时直接打开图片设置；已从本项目启动时复用已验证的本次会话。若原应用尚在运行且没有本项目端口，提示彻底退出，不强制结束用户工作。

设置支持头像 PNG/JPEG/WebP，背景 PNG/JPEG/WebP/GIF，标题、说明、字幕、透明程度，自动本地描线、保存预览、跳过、恢复默认、恢复原界面。GIF 原始字节保留。公开默认素材与图标用代码生成的几何图形，避免包含个人图片、账户资料或第三方动画。

发布包含安装 EXE、便携 ZIP、完整源码 ZIP、中文说明、构建脚本、自动化检查及上游来源说明。不自动发布 GitHub，不安装官方 Codex，不设置开机启动，不修改官方安装文件。

完成标准：新目录下可构建，已有测试通过；安装、更新、回滚、路径边界及卸载经独立临时目录验证；实际官方窗口验证设置入口和自定义图片；发布 ZIP/EXE 内容和哈希核对。声明仅在本机版本验证，其他系统未实机验证，安装器未签名。
